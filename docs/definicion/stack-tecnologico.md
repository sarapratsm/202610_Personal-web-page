# Stack tecnológico

- Framework: .NET 10
- Patrón de diseño de interfaz de usuario: MVC
- Acceso a datos: Entity Framework Core (EF Core) con Code-First y migraciones.
- Mapeo de objetos: automático con Mapperly
- Base de datos: SQLite en desarrollo (cero configuración, un simple archivo local) y PostgreSQL para producción
- Estilos: Tailwind CSS
- Compilación CSS: Tailwind CLI (Standalone) integrado en el .csproj (provisional)
- Arquitectura de software: Clean Architecture

## Tooling y Configuración
- Manejo de secretos: User Secrets en local, Variables de Entorno en producción
